# 研究室 Word（LWM01〜LWM44）

卒業論文・修士論文や学会の原稿を書く学生向けの、Word の操作を 1 回 1 機能で練習する動画講座の教材です。編集記号・ページ設定・フォント・スタイル・見出し番号・目次・セクション区切り・表と図・図表番号・数式・参考文献と相互参照・脚注・コメントと変更履歴・学会テンプレート・PDF での提出など 44 の操作を扱います。

- 動画は Windows 版の Microsoft 365 の Word（日本語）で撮影しています。
- ここに置いているのは、各回の練習用ファイルと完成見本（と、その回で挿入・コピーするファイル）だけです。
- 論文・スライドの内容と人名・所属は架空です（下の「内容はすべて架空です」）。

## 動画

動画は YouTube の再生リスト（限定公開）にまとめています: https://www.youtube.com/playlist?list=PLevMgP540Kzc

## 使い方

1. このリポジトリをダウンロードします（GitHub の「Code」→「Download ZIP」を展開する、または `git clone https://github.com/shiga-masa/lab-tutorials.git`）。
2. やり直したいときのために、練習用のファイルは **別の場所にコピーしてから** 使ってください。
3. その回のフォルダの `練習用_….docx` を開きます。動画の最初と同じ状態になっているので、動画を止めながら同じ操作をします。
4. `完成見本_….docx` は動画の最後の状態です。答え合わせに使ってください。
5. 練習用のファイルがない回（LWM02・LWM08・LWM09・LWM23）は、Word の新しい白紙の文書から始めます。
6. 表の「付属」の欄のファイル（図の .png や PowerPoint のファイルなど）は、動画の中で挿入・コピーするときに使います。
7. ファイルを開いたとき、上に黄色い帯（保護されたビュー）が出たら「編集を有効にする」を押してください。
8. 動画で「ファイル名の欄に場所を入れる」場面は、このフォルダの中のファイルを選べば同じです。

## Word の版について

- Word の版（2019・2021・2024 など）や更新の時期によって、ボタンの名前や位置が少し違うことがあります。見つからないときは、リボンの上の検索欄（「検索」や「何をしますか」）にボタンの名前を入れると探せます。
- Mac 版の Word は、メニューやショートカット（Ctrl → command など）が違います。
- 動画では表示倍率や編集記号の表示を変えていることがあります。見た目が違っても、操作の手順は同じです。
