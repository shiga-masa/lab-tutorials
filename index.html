lab-tutorials

東京都立大 地盤工学研究室の解説動画で使う教材のページです。教材（練習用データ・練習用ファイルと完成見本）は GitHub のリポジトリ https://github.com/shiga-masa/lab-tutorials に置いています。

講座

  • QGIS: 架空の InSAR・土地被覆・液状化ポリゴン・GNSS 点で、QGIS の基本操作を 1 回 1 機能で練習する動画講座（34 回、用語の説明と操作）。動画: YouTube の再生リスト（限定公開）
  • Word: 架空の論文原稿で、論文を書くための Word の操作を 1 回 1 機能で練習する動画講座（44 回）。動画: YouTube の再生リスト（限定公開）
  • PowerPoint: 架空の研究発表で、スライドとポスターを作る PowerPoint の操作を 1 回 1 機能で練習する動画講座（41 回）。動画: YouTube の再生リスト（限定公開）

練習用データはすべて教材のために作った架空のもので、実際の観測・測量・調査の結果ではありません。Word と PowerPoint の文書の内容と人名・所属も架空です。データと文書のライセンスは CC BY 4.0 です。

動画のアップロード用ツール lab-tutorials-upload

lab-tutorials-upload は、東京都立大 地盤工学研究室が自分の YouTube チャンネルに、自分で作った教材動画をアップロードするための個人用のツール（パソコンで動かすプログラム）です。一般の方に提供するサービスではありません。

このツールは YouTube API サービスを使います。

プライバシー ポリシー（lab-tutorials-upload）

最終更新日: 2026-11-03

  1. 使う情報: Google アカウントでの許可（OAuth）によって、運営者本人の YouTube チャンネルの情報（チャンネル名など）と、動画・再生リストの情報を読み書きします。動画をアップロードし、タイトル・説明・サムネイル・公開設定・再生リストを設定するためだけに使います。
  2. 保存する場所: 許可のトークンは、運営者本人のパソコンの中にだけ保存します。外部のサーバーには送りません。アップロードした動画の ID などの記録も、本人のパソコンにだけ保存します。
  3. 第三者への提供: 取得した情報を第三者に渡したり、売ったりしません。このページは広告を表示せず、Cookie などで閲覧者の情報を集めません。
  4. 許可の取り消し: このツールへの許可は、Google アカウントのセキュリティ設定のページ（https://myaccount.google.com/permissions）からいつでも取り消せます。取り消すとトークンは使えなくなります。パソコンに保存したトークンは、運営者が削除します。
  5. Google のポリシー: Google によるデータの扱いは、Google プライバシー ポリシー（https://policies.google.com/privacy）をご覧ください。
  6. お問い合わせ: https://github.com/shiga-masa/lab-tutorials/issues

利用規約（lab-tutorials-upload）

このツールは運営者本人だけが使います。このツールの利用は、YouTube 利用規約（https://www.youtube.com/t/terms）に従います。
