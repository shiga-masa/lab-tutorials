# PowerPoint（LPM01〜LPM41）

研究発表のスライドやポスターを作る学生向けの、PowerPoint の操作を 1 回 1 機能で練習する動画講座の教材です。スライドのサイズ・箇条書き・テーマのフォントと配色・スライドマスター・図形と模式図・図の書き出し・写真・表・グラフ・数式・発表スライドの構成・アニメーション・発表者ノートと発表者ツール・A0 ポスター・配布資料・PDF・コメントなど 41 の操作を扱います。

- 動画は Windows 版の Microsoft 365 の PowerPoint（日本語）で撮影しています。
- ここに置いているのは、各回の練習用ファイルと完成見本（と、その回で挿入・コピーするファイル）だけです。
- 論文・スライドの内容と人名・所属は架空です（下の「内容はすべて架空です」）。

## 動画

動画は YouTube の再生リスト（限定公開）にまとめています: https://www.youtube.com/playlist?list=PLVLLZ-tLaFgA

## 使い方

1. このリポジトリをダウンロードします（GitHub の「Code」→「Download ZIP」を展開する、または `git clone https://github.com/shiga-masa/lab-tutorials.git`）。
2. やり直したいときのために、練習用のファイルは **別の場所にコピーしてから** 使ってください。
3. その回のフォルダの `練習用_….pptx` を開きます。動画の最初と同じ状態になっているので、動画を止めながら同じ操作をします。
4. `完成見本_….pptx` は動画の最後の状態です。答え合わせに使ってください。
5. 練習用のファイルがない回（LPM01・LPM36）は、PowerPoint の新しいプレゼンテーション（白紙）から始めます。
6. 表の「付属」の欄のファイル（図の .png・.svg や写真の .jpg）は、動画の中で挿入するときに使います。
7. ファイルを開いたとき、上に黄色い帯（保護されたビュー）が出たら「編集を有効にする」を押してください。

## PowerPoint の版について

- PowerPoint の版（2019・2021・2024 など）や更新の時期によって、ボタンの名前や位置が少し違うことがあります。見つからないときは、リボンの上の検索欄（「検索」や「何をしますか」）にボタンの名前を入れると探せます。
- Mac 版の PowerPoint は、メニューやショートカット（Ctrl → command など）が違います。
- 動画では、左のスライドの一覧の幅やノートの欄の表示、表示倍率を変えていることがあります。見た目が違っても、操作の手順は同じです。
